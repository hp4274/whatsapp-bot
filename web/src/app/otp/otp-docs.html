WhatsApp OTP API

Send a one-time code to your customer's WhatsApp from your own app or website, then check the code they type. Three calls, a key in a header, JSON in and out.

Get an API key

Before you start

  1. Sign in to Wuzie and open WhatsApp OTP. Your WhatsApp number must be linked.
  2. Make an API key there. It is shown once: keep it on your server, never in an app or a web page.
  3. Send a code with /otp/send, then check what the customer typed with /otp/verify.

Connect

Address
{{ apiBase }}
Key
Send it in the header Authorization: Bearer YOUR_API_KEY (or X-API-Key). Keys start with wsk_. Only keys made on the WhatsApp OTP page can send codes.
Format
JSON in, JSON out (Content-Type: application/json). Errors answer error and message.
Safe retries
Add an Idempotency-Key header (any unique text) to a send: if your request times out and you send it again, you get the first answer back instead of a second code.
Limits
How long a code works, its tries and how often one number may get one are set per account; the account's WhatsApp OTP page shows them.
